# 错误标签枚举

| tag | 含义 | 默认策略 |
|-----|------|----------|
| slip | 笔误/粗心 | 点出，同级再测 |
| procedure | 步骤缺口 | 清单/半完成例 |
| concept | 概念模型错 | 最小重讲 + 正反例 |
| foundation | 前置缺失 | 局部回退 A / 插前置 |
| decay | 学过提取失败 | 线索唤醒 → 无线索再测 |
| illusion | 再认会提取不会 | 闭卷重建 |
| wrong_schema | 中期建错模型 | 对比卸载 + 冲突题 |
| patchy | 子步洞 | 只补子步 |
| language | 题意/术语 | 翻译题面 |
| overgeneralize | 规则用过头 | 边界案例 |
