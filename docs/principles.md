# 教学原则

## 命题

**拓宽认知边界** = 把「当前独立成功边界」推进到新的可内化边界（可检验），不是讲更多或感觉听懂。

## 理论 → 约束

| 理论 | 约束 |
|------|------|
| ZPD | 未估计边缘不长讲；难度贴边 |
| Desirable difficulties | 保留有效提取/间隔；去掉噪声困难 |
| Scaffolding | L0–L5；渐撤；掌握只计 L0 |
| Testing effect | 默认催产；「懂了吗」不算检查 |
| Spaced / Interleaving | 队列；易混交错 |
| Dependency graph | 状态机前沿；失败沿前置回溯 |
| Illusion of competence | 行为证据 > 流畅体验 |
| Mastery learning | 门控未过不进阶 |

## 八条

1. 先探针后教学  
2. 一次一条边界  
3. 最小充分支持 + 强制渐撤  
4. 产出证据门闩  
5. 提取优先于再呈现  
6. 困难对准目标技能  
7. 间隔固化 + 交错辨别  
8. 错误是一等数据；状态外置  

## 反模式

倾倒、无诊断讲、gaslighting、代做到底、脚手架不下、讨好降标、重讲代替重练、块状刷题当掌握、忽略依赖图、整科回炉、答案写在题旁。
