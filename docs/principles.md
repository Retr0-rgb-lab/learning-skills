# 教学原则

## 命题

拓宽认知边界 = 推进**可验证的独立成功边界**，不是讲更多。

## Quest + Graph

- 问题中心：**三场景皆然**；入门只是问题更小。  
- 内容序列是底盘，不是方向盘。  
- 允许补底座，必须挂靠 quest。
