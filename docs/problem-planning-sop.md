# 问题规划 SOP（强制）

大领域（整门课/学科，如 CV、QM、控制）在写 `notes/graph.md` 前必须走完本 SOP。  
小命题（单概念/单 bug）可跳 research，但仍要 goal_layer + 成功标准。

## 步骤

| # | 步 | 产出 | 通过标准 |
|---|----|------|----------|
| 1 | **Goal** `learn-route` | checkpoint.goal_layer + 可选 `_agent/goal.md` | Orient/Operate/Master 已写；有考试/项目则 GOAL_LOCK 验收条 |
| 2 | **Priors** | learner-model 或 checkpoint 备注 | 已知会/不会/债务 至少各 0–n 条；高先验标 fast_track |
| 3 | **Scope** | 一句话边界 | 学什么 / 不学什么（反课表膨胀） |
| 4 | **Research** `learn-research` | `_agent/research/sources.md` + `candidate-questions.md` | ≥1 主锚 + ≥1 对照；每锚有 URL/课名；候选问题 ≥ 目标层下限 |
| 5 | **Filter** | 候选→采用表 | 每题可验证成功标准；Operate 实践节点占比见下 |
| 6 | **Graph** `learn-graph` | `notes/graph.md` | Mermaid+节点表；无 L0–Ln 伪装；边稀疏 |
| 7 | **Seed nodes** | `notes/nodes/Q*.md` 可先 open 骨架 | 入口 1–2 个有完整 Brief |
| 8 | **Browse hooks** | `notes/wiki/index.md` 链回 graph | 学生知道从哪进 |
| 9 | **Checkpoint** | awaiting: pick_node | active_nodes 空或建议入口 |

## 节点数量与类型（按 goal_layer）

| 层 | 总节点 | practice 最少 | 说明 |
|----|--------|---------------|------|
| Orient | 5–9 | 0–1 | 地图向 |
| Operate | 8–16 | ≥30% 或 ≥3 | **能动手** |
| Master | 10–20 | ≥40% | 含迁移/变式 |

## 好问题标准（写入 graph 前自检）

- [ ] 标题是疑问句或任务句，不是「第3章 CNN」
- [ ] 有成功标准：可观察行为（算/跑/指出/对比）
- [ ] 与至少一锚有对应或明确自拟理由
- [ ] 与邻题有 gap（不连成讲义）
- [ ] Operate 下非纯定义题占多数

## 禁止

- 无 research 就对大领域出终局图
- 把公开课 schedule 复制成强制顺序
- 只有 concept、没有 practice（Operate/Master）
