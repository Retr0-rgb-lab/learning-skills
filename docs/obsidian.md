# Obsidian 用法

## 推荐

把 `learn/` 放在 vault 根或 `vault/learn/`。

## 记什么

| 层级 | 内容 |
|------|------|
| 每回合 | Tutor 问/讲、你的答/问、判定 |
| 每会话末 | Distill 五条 + quest bite |
| 每单元 | notes/unit 短结晶 |
| 你随时 | notes/user 自己的话 |

## 不要

- 只导出 AI 长讲义  
- 让 Agent 改你的 user 笔记  
- 用聊天 App 当唯一历史  

## 检索

- 搜自己的错法：sessions 里 `#### Me`  
- 按 quest：QUEST.md + frontmatter quest_id  
- Dataview：table date, scene, quest_id from "learn/topics"
