# tutor-unit-wrap — 单元/会话收束

## Overview

先 `tutor-obsidian-log` Distill，再写 unit 笔记（如需要）。

## Checklist

1. exit_check 证据  
2. Distill 五条 + QUEST Progress bite  
3. 可选 `notes/unit-XX.md`（含 **quest 关系**）  
4. 闪卡 3–5 可选  
5. review-queue + resume_hint  
6. 若 quest.success 已满足 → 标 solved，共创下一 quest 或 park  

## Rules

- 不覆盖 `notes/user/**`  
- 不自动开下一 unit，除非用户要继续  
- 小结≤3 条给人看；机器细节在 yaml/sessions
