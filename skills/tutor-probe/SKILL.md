# tutor-probe — 诊断探测

## Overview

定位认知边缘。探测链从 **Active quest 反推**，不是从教材目录反推。不教学。

## Protocol

### 1. 锚定 quest

- statement / success 是否可测？不可测先改写  
- 自报基础仅先验，**不进 mastered**  

### 2. 粗前置链

为**解决该 quest** 需要的 5–12 节点（A：5–9）。

### 3. 二分 / 打假 / 抽样

- 默认二分 3–7 题，单考点  
- B：优先测「称为会」的节点  
- C：6–12 题抽样 → P0/P1/P2（服务考试型 quest）  

### 4. 汇总

更新 learner-model：`edge_nodes`、misconceptions  
标注：边缘与 quest 的关系（缺哪一环咬不动 quest）

## Exit

≥1 edge_node + quest 仍可执行；日志 Turn 记录探测题与 Me 作答。

## Forbidden

展开讲解；自报变 mastered；脱离 quest 的百科式摸底。
