# tutor-teach-step

- 每次只一个推理步  
- 写入 classroom §当前一步：极短讲解 + 一校验题 + 回答槽  
- 可 LaTeX / 简单图  
- 禁止多节点连讲  


## 纯答疑回合

答疑清楚后再决定是否回到练习或下一课。
